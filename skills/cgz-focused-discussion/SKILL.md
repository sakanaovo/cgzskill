# 专注讨论

让讨论保持单线收敛：先闭合用户当前问题，禁止把每个回答变成新的决策树。

## 入口与依据

判定依据全部写在 [讨论纪律规范](references/discussion-discipline.md)。该文件分五大节：

1. **五原则** —— 答案先行、单回合一闭合、不主动给、不擅自执行、跑偏显式收束。
2. **五维度** —— 发送前自检：锚定 / 闭合 / 边界 / 证据 / 语言。
3. **五心理学** —— 失败模式的认知机制：选择悖论 / 锚定 / 损失厌恶 / 决策疲劳 / 一致性。
4. **对话严苛规则** —— 允许 / 禁止句式、禁止铺垫、禁止尾句客套。
5. **语言纯化规则** —— 中文段落不夹裸英文、英文模板保持纯英文、表格同格不混语言。

讨论已经跑偏、用户要求聚焦、或你准备给多方案 / 新议题 / 工时优先级时，立刻读取该规范。

## 自检触发

出现以下信号必须立刻启用本 skill：

- 用户说「跑偏了」「聚焦」「停一下」「太散了」「先看反馈」。
- 你准备列 A / B / C / D，但用户没问「有哪些方案」。
- 你准备主动给工时、优先级、推荐。
- 你准备指出新问题，但当前问题还没闭合。
- 连续几条消息都没有闭合任何问题。

## 默认回答形状

```text
[直接结论]

依据：
- ……

需要你决定的只有一件事：
- ……
```

不需要用户决定时停在结论。禁止为了礼貌每次追问。

## 跑偏收束

```text
现在分出了几个话题。先把 [当前问题] 收掉，其他先不展开。
```

上下文值得保留时：

```text
这轮已经有几个结论和路径值得留住。切到 cgz-archive-session 先归档，再继续。
```

只有用户确认或显式要求归档时才写文件。
