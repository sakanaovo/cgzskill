# cgz 启动检测

把项目共享规则和每份工作副本的本地身份、文档语言分开，一次初始化即可开始独立归档。不安装服务，不要求账号、Git 或外部应用。

## 入口与依据

扫描或生成前读取 [启动检测规范](references/init-spec.md)。该文件保留五大节：五原则 / 五维度 / 五心理学 / 对话严苛规则 / 语言纯化规则。

## 生成范围

```text
项目根/
├── .cgz/local.json           # 本地作者别名、随机 author_id 和 document_language
├── .gitignore               # 只补精确条目 /.cgz/local.json
├── AGENTS.md                # 共享入口；已有内容保留
└── docs/
    ├── cgz-memory.md        # 团队协议及 project_document_language；已有内容保留
    ├── ai-lessons.md        # 已采纳规则的稳定入口，不是并发日志
    ├── archives/           # YYYY-MM-DD-<record_id>.md
    ├── lessons/            # YYYY-MM-DD-<record_id>.md
    └── daily/              # YYYY-MM-DD-<record_id>.md
```

每份新记录使用新的随机 `record_id`，不能只靠日期、作者别名或分支名防重名。日复盘写 `docs/daily/YYYY-MM-DD-<record_id>.md` 独立文件，不争写同一天的共享文件。共享规则与本地身份分离；不会把身份配置写进共享模板。

初始化不要求 Obsidian，不询问或生成 vault 配置。已有旧配置保留不使用。其他 skill 由用户自行安装，`cgz-init` 不生成 `.claude/skills/*` 或修改用户主目录。

## 触发与授权

- 用户明确说 `/cgz-init`、初始化 cgz、启动 cgz、设置项目记忆：视为授权补齐上列骨架；先展示简短已有 / 缺失清单，将缺少的作者别名、个人文档语言和无约定时的项目共享文档语言合并确认，不逐文件重复询问。
- 只是 agent 发现缺记忆骨架：先询问是否初始化，获得确认后再执行。
- 作者别名或默认语言已明确提供时无需再问。已有有效身份直接保留；仅缺 `document_language` 的旧身份仍有效，确认语言后只补该字段，不重新生成 `author_id` 或改别名。异常、覆盖、权限限制或现有规则冲突必须停在相关项并询问。

## 最小流程

1. **扫描项目**。只检查项目内相关文件、既有归档和文档语言约定、Git 状态；不得自动扫描主目录或其他项目。分清用户项目的约定与本 skill 仓库的说明语言。
2. **确认身份与语言**。首次确认作者别名；`git user.name` 只作候选，不代表认证，不取邮箱。无 Git 时直接询问。提供中文（`zh-CN`）、英文（`en`）、其他（由用户指定）选项，将确认的个人默认语言保存为 `document_language`。新身份用安全随机 UUID 生成 `author_id`，按 [身份模板](assets/local.json.template) 写 `.cgz/local.json`，只在本项目 `.gitignore` 中补 `/.cgz/local.json`。已有身份只补或按明确的长期偏好变更更新语言字段；单次输出语言请求不改配置。
3. **确定共享语言**。团队共享 `AGENTS.md`、协议和已采纳规则遵守已有项目语言，个人配置不能覆盖。项目没有明确约定时，在同一次确认中询问共享文档语言，并记录 `project_document_language: <tag>` 到 `docs/cgz-memory.md`。已有协议缺标记时只在语言已确认、无冲突且可安全追加时补一行；不重写原文，不增设第二套配置。
4. **补齐骨架**。共享协议用 [协议模板](assets/cgz-memory.md.template)，共享入口用 [AGENTS 模板](assets/AGENTS.md.template)，稳定教训入口用 [教训模板](assets/ai-lessons.md.template)。归档目录说明用 [归档说明模板](assets/archives-README.md.template)。把新共享模板的标题和说明渲染为项目语言，保留路径、字段、ID、状态值和来源原文。仅创建缺失文件和目录，并按规范最小追加必要入口或语言标记；已有内容不覆盖、不搬移、不删历史。
5. **核对后收尾**。验证本地 JSON 可解析、身份字段和 UUID 有效、语言选择已记录、忽略条目精确且无重复。确认身份文件未被跟踪；已被跟踪时警告并询问，不自动删除文件或改写 Git 历史。

再次运行时，身份、语言选择、协议和入口齐全则不写文件、不换 ID、不追加重复说明。不同 worktree 或工作副本分别保留自己的 `.cgz/local.json`，不写共享 Git 配置；同一作者多会话依靠每次新 `record_id` 区分。

## 文档语言

个人新文档按「本次明确要求 > 本地 `document_language` > 项目约定 > 首次询问」选择；不得从系统区域、输入法、作者姓名或本仓库 README 猜测偏好。首次确认的默认选择持久保存；后续只有明确要求长期修改时更新该字段。共享文档始终遵守项目语言约定，修改共享约定需另有明确授权。

语言切换只影响之后新建的文档，不回写或批量翻译历史。来源原文和引用保持原样；需要翻译时另列并标明译文，不能把译文冒充直接引文。这些是宿主 agent 执行的语言规则和模板，不是可执行翻译引擎；各语言实际生成效果需宿主验收。

## 收尾

回复 ≤ 12 行，包含「生成」「保留未动」「下一步」或所选语言的对应表达，并说明个人及共享文档语言。只报告实际结果和阻塞；不能把未完成身份或语言设置称为就绪。下一步指向独立归档 / 教训记录，不让用户先搭账号或手改业务配置。

## 禁止

- 禁止覆盖已有身份、共享规则、协议或历史记录；已确认的语言字段最小更新不等于重建身份。
- 禁止把新教训直接追加到共享 `AGENTS.md`、`ai-lessons.md` 或索引。
- 禁止改业务代码、自动提交、自动合并、后台监听或宣称已经实现同步服务。
- 禁止每次会话重跑；仅显式请求或确认初始化时执行。
